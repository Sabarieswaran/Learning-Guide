# Company Interview Guides

## Overview

These guides cover the frontend interview processes at major companies that hire Angular developers. Each guide includes:

- Interview process and number of rounds
- Primary focus areas per round
- Frequently asked questions (verified where possible)
- Preparation strategy

---

## Companies Covered

| Company | Primary Stack | Interview Focus |
|---|---|---|
| [JPMorgan Chase](./jpmorgan) | Angular, Java | Performance, security, TypeScript depth |
| [Microsoft](./microsoft) | Angular, React, TypeScript | System design, accessibility, behavioral |
| [Adobe](./adobe) | Angular, React | Component APIs, design systems, creative tools |
| [Flipkart](./flipkart) | React, Angular | Machine coding, DSA, scale |
| [Oracle](./oracle) | Angular, Java | Enterprise patterns, Oracle JET, testing |

---

## What All These Companies Share

Despite different stacks and cultures, every senior frontend interview at a product company tests:

1. **JavaScript internals** — event loop, closures, prototypes, async
2. **TypeScript** — generics, utility types, strict mode
3. **Angular depth** — change detection, DI, signals, performance
4. **Problem solving** — live coding (machine coding or DSA)
5. **System thinking** — designing a scalable UI feature
6. **Communication** — explaining technical decisions clearly

---

## General Preparation Timeline

```
Weeks 1–2: JavaScript & TypeScript internals
Weeks 3–4: Angular deep dive (signals, CD, DI, routing)
Weeks 5–6: System design (2 full designs per week)
Week 7: Machine coding practice (1 problem/day)
Week 8: Company-specific prep + mock interviews
```
