# Information Architecture

## Purpose

This document defines the complete information architecture for the
Learning Guide website. Its goal is to ensure every topic has a clear
place, navigation remains consistent, and users can move naturally from
beginner concepts to senior-level engineering topics.

# Sidebar Strategy

Each section contains:

-   Overview
-   Fundamentals
-   Intermediate
-   Advanced
-   Interview Questions
-   Exercises
-   Cheat Sheet

Example:

HTML - Introduction - Document Structure - Semantic Elements -
Accessibility - Forms - SEO - SVG - Canvas - APIs - Best Practices -
Interview Questions

# Cross Linking Rules

Every page should contain:

-   Previous Topic
-   Next Topic
-   Related Topics
-   Prerequisites
-   Suggested Next Reading

# Content Relationships

Every advanced topic must link back to required fundamentals.

Example:

Signals requires: - Change Detection - Components - Dependency Injection

------------------------------------------------------------------------

# Interview Mode

Each page exposes:

-   30 Second Answer
-   Detailed Answer
-   Senior Answer
-   Common Mistakes
-   Follow-up Questions

------------------------------------------------------------------------

# Revision Mode

Generate condensed revision pages containing:

-   Key Concepts
-   Diagrams
-   Frequently Asked Questions
-   Cheat Sheet
-   Common Traps

------------------------------------------------------------------------

# Expansion Rules

Never create duplicate topics.

If a topic grows too large: - Split into logical sub-pages. - Keep
navigation stable. - Preserve backlinks.

------------------------------------------------------------------------

# Information Architecture Principles

-   Mobile-first navigation.
-   Maximum three clicks to any topic.
-   Consistent naming.
-   Predictable sidebar.
-   Strong internal linking.
-   Prefer breadth first, then depth.
-   Keep learning flow progressive.
