## Learning Guide -- Project Specification

**Version:** 1.0\
**Status:** Active

# 1. Vision

## Mission

Build the world's best Angular & Frontend Engineering Learning Guide as
an open-source documentation website.

## Objectives

-   Angular-first
-   Enterprise quality
-   Official references
-   Interview focused
-   Production examples
