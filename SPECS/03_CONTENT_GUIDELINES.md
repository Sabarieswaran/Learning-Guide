# 03_CONTENT_GUIDELINES

## Purpose

Defines writing standards for every chapter.

## Writing Principles

-   Original content only.
-   Explain **Why, How, When, Trade-offs**.
-   Prefer Angular examples.
-   Avoid filler and repetition.
-   Link related chapters.

## Chapter Template

1.  Introduction
2.  Why it matters
3.  Simple explanation
4.  Technical explanation
5.  Internal working
6.  Diagram (Mermaid)
7.  Angular example
8.  Production example
9.  Performance
10. Accessibility
11. Security (if applicable)
12. Common mistakes
13. Best practices
14. Interview questions
15. 30-second answer
16. Detailed answer
17. Senior answer
18. Exercises
19. Cheat sheet
20. Official references

## Interview Questions

-   Difficulty (Easy/Medium/Hard/Senior)
-   Asked in (if verified)
-   Follow-up questions
-   Common mistakes

## Code Standards

-   Runnable
-   Syntax highlighted
-   Explained line-by-line when needed

web.dev, Learn RxJS.
